API:Appliction Arogramming Interface

API is a set of rules and protocols that allows different software applications to communicate with each other.

API

    

  • Application:The software program that offers or use the functionality
    • 

  • Programming:The code-level way other programs ask for that functionality
    • 

  • Interface:The agreed meeting point between them,define by the requests you can make,
the data format,and the response you get back.

    •

FRONTEND AND BACKEND

    

  • Front end: the part of an app the user sees and 
interacts with, such as the web page, button, or 
mobile screen. It sends API requests, for example 
"show my invoices".
    • 

  • Server(back end): the part that runs out of the user's view, stores data, and handles the logic. It receives the request, processes it, and sends back a response,such as the list of invoices in JSON.

    •

API KEY

An API key is a unique string of letters and numbers that identifies who is making a request to an API. It works like a password for your application: the server checks the key to decide whether to accept the request, who is calling, and how much they're allowed to use.

What it's used for

  • Identification: the provider knows which account or app is making the call.
  • Access control: some APIs only allow certain actions for certain keys.
  • Usage tracking and limits: providers count requests per key to enforce rate limits or bill for usage.

WHAT IS MCP

MCP is a universal bridge between AI apps and external tools-build the integretion once,and it works across any model or tool update.

MODEL

An AI model(LLM) that understands and generates responses for user.

CONTEXT

The information the modle can see in one request: the system prompt,any tool results.The model only know in context window.

PROTOCOL

A set of rules to communicate between two syatem . HTTP is one example.

Three parts of an MCP setup

HOST/CLIENT APP

The application where you can chat with AI and that manages coonections.

MCP SERVER

A program that exposes tools, data and templets in the standard format.

UNDERLYING SYSTEM

The real service or data the server works with.
